# kind
**kind(Kubernetes in Docker)란?** Docker 컨테이너 기반으로 노드를 사용해로컬 로컬 Kubernetes 클러스터를 실행하기 위한 도구이다. 주로 Kubernetes 자체 테스트하기 위해 설계되었지만 로컬 개발 환경 구축, CI/CD 파이프라인 테스트 등에도 활용된다.

**Docker와 Go 환경**이 갖춰져 있다면 간단한 명령어로 **Kubernetes 클러스터를 구축**할 수 있다. 비교적 가벼운 환경에서도 Kubernetes를 실행할 수 있어 **실습 및 개발에 적합**하다.

Go : 1.16+ 버전 이상 사용   
Docker 또는 Podman 설치

```bash
# Go 설치
go install sigs.k8s.io/kind@v0.20.0 && kind create cluster
```

## 주요 특징
**Docker 컨테이너 = Kubernetes 노드 :** 별도의 VM이나 클라우드 인스턴스 없이 도커 컨테이너 하나하나를 노드처럼 사용해서 클러스터를 구성한다. 그래서 노트북에서도 몇 초~몇 분 안에 멀티노드 클러스터를 띄우고 지울 수 있다.

**Upstream(순정) Kubernetes 사용 :** k3s처럼 컴포넌트를 경량화한 배포판이 아니라 kubeadm 기반의 진짜 쿠버네티스를 그대로 쓴다. 그래서 실제 프로덕션 클러스터와 동작 방식이 거의 동일하고 k8s 자체 버그 재현이나 신규 버전 테스트에 적합하다. 실제로 Kubernetes 프로젝트 자체의 CI에서 공식적으로 사용되는 도구이다.

**선언적 멀티노드 구성 (HA 토폴로지 지원) :** YAML 설정 파일 하나로 컨트롤플레인 여러 개, 워커 노드 여러 개를 조합한 복잡한 토폴로지를 코드로 정의하고 재현할 수 있다.

# k3d
**k3d란?** k3s(경량 Kubernetes 배포판)를 Docker 컨테이너 안에서 실행하기 위한 도구이다. Rancher(현재는 SUSE)에서 만든 **k3s를 로컬 환경에서 더 쉽게 다루기 위해 커뮤니티를 만든 래퍼 도구**이다.

```bash
# 설치 (curl 스크립트)
curl -s https://raw.githubusercontent.com/k3d-io/k3d/main/install.sh | bash
```

## 주요 특징
**k3s 기반 가볍고 빠름 :** 쿠버네티스 컴포넌트가 단일 바이너리로 경량화된 k3s를 그대로 쓴다. etcd 대신 기본적으로 SQLite를 사용하고 불필요한 클라우드 프로바이더 관련 코드 등이 빠져 있어서 kind보다 리소스 사용량이 적고 클러스터 생성 속도도 더 빠른 편이다.

**로드밸런서 자동 구성 :** 클러스터 생성 시 `k3d-<클러스터명>-serverlb`라는 컨테이너가 자동으로 함께 뜨는데 이게 nginx 기반 로드밸런서 역할을 하면서 여러 서버 노드로 트래픽을 분산시켜준다. kind는 이 부분을 직접 설정해야 하는 것과 대비되는 지점이다.

**멀티 서버/에이전트 노드 구성이 간단 :** CLI 옵션만으로 서버(컨트롤플레인) 노드와 에이전트(워커) 노드 개수를 손쉽게 지정할 수 있다.

# Kind와 k3d의 차이점
가장 핵심적인 차이점은 **컨테이너 안에서 어떤 쿠버네티스를 돌리는가?**의 차이다.
| 구분 | kind | k3d |
| --- | --- | --- |
| 내부 k8s | Upstream Kubernetes (Kubeadm 기반) | k3s(경량화 배포판) |
| 주 목적 | k8s 자체 개발/테스트, CI(k8s 프로젝트 공식 CI 도구) | 빠르고 가벼운 로컬 개발/실습 |
| 설치 요구사항 | Docker + Go | Docker만 있으면 됨 |
| 리소스 사용량 | 상대적으로 무거움 | 훨씬 가벼움 (단일 바이너리) |
| 로드밸런서 | 없음 → 직접 설정 필요 | `serverlb` 컨테이너 자동 생성 (nginx 기반) |
| Ingress Controller | 없음 → 별도 설치 필요 (nginx-ingress 등) | Traefik 내장 |
| 컨테이너 구성 | 노드 = 컨테이너 (컨트롤플레인/워커) | 노드 = 컨테이너 + 로드밸런서 컨테이너 추가 |
| 클러스터 생성 속도 | 상대적으로 느림 | 더 빠름 |
